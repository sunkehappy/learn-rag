## Overview

We believe in staying up to date with security patches on all endpoint operating systems and installed software to mitigate the risk of exploitable vulnerabilities.

## What to Expect

When a new macOS version is released, it is first validated by our Security beta testers before it is rolled out to the fleet. Once it reaches your Mac, you will receive standard update notifications and will need to restart to finish installing by a deadline. Installing early, at a time that suits you, is always the smoother experience.

Plan for software updates to take 30-60 minutes. It is easiest to do this towards the end of your workday or work week, so you can save your work and close any application windows before restarting.

GitLab team members: for the full macOS update policy, including version requirements and enforcement timelines, see the internal handbook page [Approved Team Member Endpoint Operating Systems](https://internal.gitlab.com/handbook/security/corporate/operating-systems).

## Configuration Steps

You need to ensure that macOS is configured to perform automatic software updates for security patches.

All applications should regularly be checked for updates by navigating to the application name in the top left of the menu bar and choosing the `About` or `Check for Updates` option (varies by application).

If you use `brew` or a package manager, it can keep your [software updated automatically](https://docs.brew.sh/FAQ#how-do-i-update-my-local-packages).
