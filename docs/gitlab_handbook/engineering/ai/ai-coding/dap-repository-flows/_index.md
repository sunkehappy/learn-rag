## Overview

The DAP Repository Flows team works on two related areas:

**DAP Onboarding**: Creating files and configuration that make a project more agentic — helping repositories become AI-ready so Duo features can work effectively within them.

**Background Agents / Repository Flows**: Autonomous flows that run in the background for a repository to proactively improve it over time — finding missing tests, writing documentation, keeping code up to date, and more. These flows run without requiring manual invocation, making repositories continuously better.
