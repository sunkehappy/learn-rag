{{% alert title="This page has moved" color="warning" %}}
The **Production Readiness Review (PRR)** process has been retired and replaced by the **Production Readiness Enablement Process (PREP)**.

PREP covers everything PRR did. Please use PREP for all new and existing production readiness work:

- **PREP handbook**: [/handbook/engineering/infrastructure-platforms/production/prep/](/handbook/engineering/infrastructure-platforms/production/prep/)
- **Start a PREP Assessment**: [gitlab.com/gitlab-org/architecture/readiness](https://gitlab.com/gitlab-org/architecture/readiness)
- **PREP meta project**: [gitlab.com/gitlab-com/gl-infra/prep/meta](https://gitlab.com/gitlab-com/gl-infra/prep/meta)

The legacy `gl-infra/readiness` project has been archived. If you have an existing workflow built around PRR, PREP is where it lives now.
{{% /alert %}}
